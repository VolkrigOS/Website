Wi-Fi (Ethernet)

If you run ip a, probably will return something like this

1: lo: LOOPBACK mtu 65536 qdisc noop state DOWN qlen 1000
    link/loopback  00:00:00:00:00:00 brd  00:00:00:00:00:00
2: example:  mtu 1500 qdisc noop state DOWN qlen 1000
    link/ether  12:12:2:12:12:12 brd  ff:ff:ff:ff:ff:ff

Then, run: 

volkrigos :: root@ /root
❯ dhcpcd # Set the IPs
volkrigos :: root@ /root
❯ echo "nameserver 8.8.8.8\nnameserver 8.8.4.4" > /etc/resolv.conf
# DNS for searching

And then, use ping google.com to check.
