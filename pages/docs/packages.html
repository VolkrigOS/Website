packages

First, to install packages you will need

wget and vpkg (Default for the system)

Check for wifi using ip a

Having problems with internet? Click here!

Let's install apt for example

wget -o apt https://raw.githubusercontent.com/pietroago/volkrigOS/refs/heads/main/packages/x86/apt.vpkg vpkg -i ./apt.vpkg

And now, you have apt, but for anothers packages you can use our official repository or another repository
