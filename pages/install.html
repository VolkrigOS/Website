install

install Volkrig OS on your system.

requirements

  • x86-64 system
  • internet connection
  • git

download

clone the Volkrig OS repository: 

git clone https://github.com/pietroago/volkrig.github.io.git

enter the directory

cd volkrig.github.io

source

the source code is available at github .
